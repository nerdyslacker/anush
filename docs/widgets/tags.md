# Tags

Shows the current, occupied, and urgent skarwm tags. Optional paging limits how
many tags appear on the bar at once.

## Actions

- **Left click a tag:** View that tag.
- **Middle click a tag:** Send the focused window to that tag.
- **Right click a tag:** Open tag settings.

  ![Tags Right Click](screenshots/tags_right_click.png)

- **Scroll:** Cycle through tags.
- **Arrow click:** Show the previous or next page when a visible-tag limit is active.

  ![Tags Arrow Click](screenshots/tags_arrow_click.png)
