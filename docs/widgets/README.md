# Bar widgets

Each page describes one widget available in the bar settings. Screenshot
placeholders are intentionally left in place for project screenshots.

| Widget | Purpose |
| --- | --- |
| [Launcher](launcher.md) | Search, launch, and favorite applications |
| [Tags](tags.md) | View and control workspaces/tags |
| [Window list](window-list.md) | Focus grouped application windows |
| [Layout picker](layout-picker.md) | Layout, appearance, and wallpaper controls |
| Window title | Focused-window title |
| [Scratchpads](scratchpads.md) | Registered scratchpad windows |
| [Media](media.md) | MPRIS playback status and controls |
| [Weather](weather.md) | Current conditions and forecast |
| [System metrics](system-metrics.md) | CPU, memory, and disk usage |
| [Battery](battery.md) | Charge and power controls |
| [Brightness](brightness.md) | Per-display brightness controls |
| [Audio](audio.md) | Volume, mixer, and effects |
| [tmux](tmux.md) | tmux session manager |
| Muted mic | Muted microphone warning |
| [Network](network.md) | Connections, VPN, and hotspot controls |
| [Bluetooth](bluetooth.md) | Bluetooth status and devices |
| [Keyboard](keyboard.md) | Keyboard layout selection |
| [Clipboard](clipboard.md) | Clipboard history |
| [Color picker](color-picker.md) | Screen color picker and history |
| [Notepad](notepad.md) | Sidebar notes |
| [System tray](system-tray.md) | StatusNotifier items |
| DND indicator | Do-not-disturb status |
| [Clock](clock.md) | Time, calendar, and events |
| Caps Lock | Caps Lock warning |
| Screenshot | Flameshot launcher |
| [Commands](commands.md) | Session commands and bar settings |

The System updates component exists in the source tree but is not currently
registered in the bar widget catalog. The other pages correspond directly to
the widgets available from bar settings.
